# سامانه تشخیص آرایه‌های ادبی در متون فارسی

## معرفی پروژه

این پروژه یک برنامه مبتنی بر پایتون است که با هدف شناسایی و تحلیل آرایه‌های ادبی در شعرها و متون فارسی توسعه داده می‌شود.

هدف اصلی آن کمک به تشخیص دقیق‌تر آرایه‌های ادبی، ارائه شواهد متنی و توضیح دلایل تشخیص هر آرایه است.

## اهداف پروژه

- شناسایی آرایه‌های ادبی در متون فارسی
- افزایش دقت تشخیص آرایه‌ها
- کاهش تشخیص‌های اشتباه و پاسخ‌های کاذب
- ارائه شواهد متنی برای آرایه‌های شناسایی‌شده
- توضیح دلیل تشخیص هر آرایه
- بررسی میزان اطمینان سیستم به نتایج

## آرایه‌های ادبی

این پروژه با هدف پشتیبانی از آرایه‌های مختلف ادبی از جمله موارد زیر توسعه داده می‌شود:

- تشبیه
- استعاره
- تشخیص
- کنایه
- مجاز
- ایهام
- تضاد
- تناقض
- مراعات نظیر
- تلمیح
- تضمین
- واج‌آرایی
- جناس
- سجع
- اغراق
- حس‌آمیزی
- حسن تعلیل

## فناوری‌های مورد استفاده

- Python

## وضعیت توسعه

این پروژه در حال توسعه است و قابلیت‌های آن به‌مرور گسترش پیدا می‌کنند.

تمرکز اصلی توسعه بر افزایش دقت تحلیل، کاهش خطاها و بهبود کیفیت توضیحات ارائه‌شده توسط برنامه است.

## نکته

تشخیص آرایه‌های ادبی در زبان فارسی به دلیل وابستگی به بافت، معنا و مفهوم متن، همیشه با چالش‌هایی همراه است. بنابراین نتایج برنامه باید با توجه به مفهوم کلی متن بررسی شوند.
